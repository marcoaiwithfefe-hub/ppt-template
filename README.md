# 用公司 PPT 範本出簡報

將你嘅筆記變成一份用公司範本做嘅 PowerPoint。每個標題、每一點都放入範本本身嘅格仔，公司 logo、顏色、字體原封不動，下載之後照樣可以改。

網頁：https://marcoaiwithfefe-hub.github.io/ppt-template/

## 點用

1. 喺網頁撳「複製」，貼落 Gemini，再貼埋你嘅筆記。Gemini 會俾你一段大綱。
2. 將公司範本（`.pptx` 或 `.potx`）拖入網頁。
3. 貼返段大綱，撳下載。

範本同簡報全程留喺你部電腦：網頁載入完之後唔會再連網，熄咗 Wi-Fi 都用得。大綱嗰一步會將筆記交俾 Gemini；唔想交嘅話，可以跟網頁個例子自己打大綱。

## 加入 Gemini skill

適合個人 Gemini 帳戶。

1. 下載 `skill/ppt-outline/SKILL.md`。
2. 去 gemini.google.com，左邊揀 Customize，再揀 Skills，撳 Create，揀 Upload，揀呢個檔案。
3. 之後喺 Gemini 打 `/`，揀 ppt-outline，再貼筆記。
